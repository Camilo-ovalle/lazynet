## Claude Code notes

- Project rules live in `AGENTS.md` (imported above), so other agents share them. Put changes to rules or project status there, not here.
- Claude Code's auto-memory (`~/.claude/projects/…`) stays on each machine. When you learn something durable about the project, also record it in `AGENTS.md` so it survives a change of PC.
- `.claude/settings.json` holds the shared permission allow-list. Personal overrides go in `.claude/settings.local.json`, which is git-ignored.
